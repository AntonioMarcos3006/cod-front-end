# Desenvolvimento Front-End — SENAI Florianópolis

Repositório destinado aos estudos, exercícios e projetos desenvolvidos durante o curso de Desenvolvimento Front-End no SENAI Florianópolis.

## Sobre o Repositório

Este repositório reúne atividades realizadas ao longo do curso, registrando minha evolução no desenvolvimento web e servindo como organização dos projetos e conteúdos estudados.
